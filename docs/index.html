À retenir

1. Classement des applications

La note ajustée corrige les apps qui ont très peu d'avis : chacune démarre comme si elle avait déjà avis à la note moyenne du secteur. Une app avec 5 avis à 5/5 ne passe donc pas devant une app avec 5 000 avis à 4,7/5.

Note ajustée par application (sur 5)

Plus la barre est longue, plus les utilisateurs sont satisfaits. Survolez une barre pour le détail.

Détail par application

Cliquez sur un en-tête pour trier. « Fourchette » = marge d'incertitude à 95 % du pourcentage d'avis négatifs : plus l'app a d'avis, plus elle est étroite.

3. Pourquoi les utilisateurs se plaignent

Part des avis négatifs (1–2★) qui citent chaque sujet

Un avis peut citer plusieurs sujets. Comparez les deux couleurs : les banques et le mobile money n'ont pas les mêmes problèmes.

Gravité des sujets

« Note quand cité » : note moyenne des avis qui parlent de ce sujet (plus c'est bas, plus le sujet fâche). « Votes utile » : nombre de fois où d'autres utilisateurs ont approuvé ces plaintes.

Sujets de plainte, application par application

Pour chaque app (au moins avis négatifs) : % de ses avis négatifs qui citent le sujet. Plus la case est foncée, plus le sujet pèse dans ses plaintes.

Chaque avis indique la version de l'app utilisée. On peut donc voir quelles versions ont fait monter ou chuter la satisfaction (versions avec au moins avis).

Qui répond, et comment

« Messages types » : réponses dont le début est identique mot pour mot à au moins 2 autres réponses de la même app.

7. Ce que disent les utilisateurs

Les avis les plus approuvés par les autres utilisateurs (votes « utile »), pour chaque sujet. Les noms des auteurs ne sont pas affichés.
